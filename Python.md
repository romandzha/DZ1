## Настройка репозитария:
Чтобы любые изменения были подписаны вашим именем, введите персональные данные:
> git config --global user.name "_здесь между кавычками ввести имя_"
> git config --global user.email "_здесь мужду кавычками ввест свой адрес_"
> git config --global --list проверка того, что изменилось
Задайте правильный формат строк (для Windows):
> git config --global core.autocrlf true
> git config --global core.safecrlf warn
Избегать нечитаемых строк в неправильной кодировке:
> git config --global core.quotepath off
Задать имя основной ветки в репозитории Git — main:
> git config --global init.defaultBranch main
Запросить подсказку по всем командам:
> git help -g
Запросить подсказку по конкретной команде:
> git help -g

## Создание локального репозитария:
Выбрать папку и исполнить команду:
> git init
Проверить текущее состояние файлов:
> git status
Добавить файл в отслеживаемые:
> git add _имя файла_
> git add -A
    добавить сразу все файлы (вкл. новые, измененные и удаленные)
> git add .
    только новые и измененные
> git add -u
    только измененные и удаленные

Закоммитить:
> git commit -m "_имя коммита_"

Просмотр истории проекта:
> git log --oneline
    выводится список коммитов снизу вверх - от старых к новым - с указанием хэша
> git log
    выводится вся информация о проекте
    если много информации - можно прервать *Q*
Переключиться на нужный коммит:
> git checkout _хэш коммита_
> git checkout main
    вернуться к последнему коммиту
Изменение коммита:
> git commit --amend -m "_новое имя коммита_"
Показать всю историю, вне зависимости от того, на каком коммите нахожуьс:
> git log --all --oneline


## Работа с удаленным репозитарием:
Сгененрировать SSH-ключ:
> ssh-keygen
    на запрос куда - Enter
    в строке Your public key has been saved in /c/Users/user/.ssh/id_rsa.pub скопировать окончание пути, начиная с /.ssh/
>  cat ~_имя пути_
    скопировать SHH-ключ
    добавить по ссылке NewSSH https://github.com/settings/keys
Проверить, что еще нет связей с репозиторием:
> git remote -v
    ответ должен быть пустым
Связать репозитории:
> git remote add origin _ссылка на папку удалённого репозитория_
Удалить связь:
> git remote remove origin
Отправить в удаленный репозиторий:
> git push -u origin main
    только в первый раз, далее можно писать только git push

## Топ-10 команд Git

> git add — добавить изменения в область подготовки (staging area)
> git status — получить сводку о том, какие файлы имеют изменения, подготовленные для следующего коммита
> git commit — запись изменений, сделанных в файлах области подготовки, в репозиторий
> git reset — отмена подготовленных изменений в файлах области подготовки
> git clean — удаление неотслеживаемых файлов из рабочего каталога
> git merge — объединение изменений из одной ветки в другую
> git fetch — получение последних изменений из удалённого репозитория
> git push — отправка изменений из локального репозитория в удалённый репозиторий
> git pull — получение последних изменений из удалённого репозитория и автоматического объединения их с текущей веткой
> git checkout — переключение между ветками или восстановления файлов из предыдущих коммитов

## Списки
- cписок инициализируется при помощи [ ], элементы разделяются запятыми;
- в одном списке могут быть одновременно элементы разных типов, включая другие списки.
- два основных способа работы со списками:
    - перебор элементов в цикле
    - работа с индексом элементов
- в отличие от кортежей и множеств, элементы в списках можно изменять

## Операции со списками
- Списки можно складывать
- del(list[index]) удаляет элемент из списка по индексу
- .remove(el) удаляет указанный элемент из списка
- .append(el) позволяет добавить элемент в список
- .count(el) считает количество вхождений элемента в список
- .index(el) позволяет узнать индекс элемента в списке
- .reverse() разворачивает список
- sorted(list) сортирует список
- копирование через импортируемый модуль copy
Можно менять элементы списка при помощи индексации и срезов, т. к. списки изменяемы

## Кортежи (tuples)
- неизменяемые списки
- нельзя добавлять или удалять элементы из уже созданного кортежа
- кортежи инициализируют при помощи ( )
    - в кортеже из одного элемента должна присутствовать запятая
- требуют меньше памяти, чем списки

Функция zip(list_1, list_2, ...) берёт на вход несколько списков и создаёт из них специальный zip-объект, состоящий из кортежей.
- первый элемент полученного объекта содержит кортеж из первых элементов всех списков-аргументов

## Циклы
- WHILE
    - позволяет выполнить одну и ту же последовательность действий, пока проверяемое условие истинно
    - цикл используют, когда невозможно заранее определить точное значение количества проходов исполнения цикла
    - задается (1) условие, (2) код, который будет выполняться, пока условие True
- FOR
    - цикл for проходится по элементам любого итерируемого объекта (строки, списка и т. д.)
    - во время каждого прохода выполняет заданную последовательность действий
    - задачется (1) имя, которое будет присваиваться элементу при каждой итерации, (2) имя объекта, по которому итерируется, (3) код, который будет
исполняться при каждой итерации

Ключевые слова:
- break
    прерывает исполнение цикла
- continue
    завершает исполнение текущей итерации цикла и переходит к следующей итерации
- pass
    игнорирует условие и продолжает исполнение цикла
